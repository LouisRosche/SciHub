# 🧪 SciHub - NGSS-Aligned Science Learning Platform

**Daily Notecards + Chromebooks = Science Mastery**

SciHub is a comprehensive science teaching system designed for grades 6-8 that combines the tactile benefits of physical notecards with the power of digital technology. Built on NGSS three-dimensional learning (DCI + CCC + SEP), project-based pedagogy, and personalized learning paths.

## 🌟 Core Philosophy

Every student submits **one meaningful notecard per day** as their primary learning artifact. This daily practice:
- Creates consistent engagement and accountability
- Builds long-term retention through spaced repetition
- Provides teachers with authentic assessment data
- Develops scientific thinking and communication skills
- Allows for personalization and student voice

## 📚 NGSS Three-Dimensional Learning

Every notecard and project integrates all three dimensions:

### Disciplinary Core Ideas (DCI)
- **Physical Sciences (PS)**: Matter, forces, energy, waves
- **Life Sciences (LS)**: Cells, heredity, ecosystems, evolution
- **Earth & Space Sciences (ESS)**: Earth systems, space, human impacts
- **Engineering (ETS)**: Design process, optimization, solutions

### Crosscutting Concepts (CCC)
1. Patterns
2. Cause and Effect
3. Scale, Proportion, and Quantity
4. Systems and System Models
5. Energy and Matter
6. Structure and Function
7. Stability and Change

### Science & Engineering Practices (SEP)
1. Asking Questions and Defining Problems
2. Developing and Using Models
3. Planning and Carrying Out Investigations
4. Analyzing and Interpreting Data
5. Using Mathematics and Computational Thinking
6. Constructing Explanations and Designing Solutions
7. Engaging in Argument from Evidence
8. Obtaining, Evaluating, and Communicating Information

## 💡 The Daily Notecard System

### Why Notecards?

Physical notecards provide unique benefits:
- **Dual Coding**: Blank side (visual) + lined side (written)
- **Portability**: Students can review anywhere
- **Tangible Progress**: Physical stack shows accomplishment
- **Memory Enhancement**: Writing by hand improves retention
- **Assessment**: Quick, authentic formative assessment

### Notecard Structure

**Front Side (Blank)**: Visual thinking
- Diagrams and sketches
- Models and systems
- Data tables and graphs
- Observations and photos
- Concept maps

**Back Side (Lined)**: Written thinking
- Explanations with evidence
- Claims and reasoning
- Reflections and connections
- Analysis and interpretation
- Questions and wonderings

### Daily Workflow

1. **Morning**: Student sees today's prompt (tied to current project)
2. **During Class**: Student works on project, collects observations/data
3. **End of Class**: Student creates notecard (front + back)
4. **Submission**: Physical card submitted to teacher
5. **Digital Entry**: Student also logs card in SciHub (photo + text)
6. **Teacher Review**: Teacher provides feedback within 24 hours
7. **Spaced Repetition**: Card enters review queue for future practice

## 🚀 Getting Started

### Installation

```bash

git clone https://github.com/yourusername/SciHub.git
cd SciHub

# Install dependencies
npm install

# Start development server
```

1. **Print Notecard Templates**

   - Print on cardstock for durability

2. **Choose Projects**

3. **Set Up Student Accounts**
   - Create student profiles
   - Set their grade level and interests

4. **Establish Routines**
   - Daily: Collect physical notecards

4. **Submit** both physical and digital versions
5. **Review** past notecards to strengthen memory

## 🎓 Pedagogical Approach

### Personalization Strategies

1. **Project Choice**: Students select from multiple projects
2. **Within-Project Choice**: Every project has 4-6 choice points
3. **Interest-Based**: Projects recommended based on student interests
4. **Pace Flexibility**: Students work at appropriate speed
5. **Expression Options**: Multiple ways to demonstrate understanding

### Assessment Philosophy

- **Daily Formative**: Every notecard provides insight
- **Standards-Based**: Track mastery of specific NGSS standards
- **Growth-Oriented**: Focus on progress over time
- **Student Voice**: Self-assessment built into every card
- **Authentic**: Real scientific thinking, not memorization

### Spaced Repetition Science

Research shows spaced repetition increases retention by 200%+. SciHub uses:
- **Initial Learning**: Create notecard on day of learning
- **First Review**: 1-3 days later
- **Second Review**: 3-7 days later
- **Subsequent Reviews**: 14, 30, 60 days (adaptive based on mastery)

Students rate their recall (Easy/Medium/Hard), and the algorithm adjusts review intervals.
